# Visual Identity

## Purpose

The identity represents a bounded builder harness: prompt cards enter controlled workbenches, pass deterministic checkpoints, leave evidence in a ledger, and produce one selected browser-world proof.

It intentionally avoids generic robot, brain, cloud, and science-fiction imagery.

## Palette

| Role | Color |
| --- | --- |
| Primary structure | `#0B5D46` |
| Builder surface | muted teal |
| Validation signal | warm yellow |
| Review exception | brick red |
| Text and deep contrast | charcoal |
| Paper background | `#F4EEDC` |

## Assets

All reusable files are under [`docs/assets/brand/`](assets/brand/):

- `logo-transparent.png` is the full-resolution transparent mark.
- `logo-1024.png`, `logo-512.png`, and `logo-256.png` are normalized variants.
- `logo-mask.png` and `logo-mask.svg` support recoloring.
- `cover-1280x640.png` is the uncropped repository cover.
- `social-card.png` combines the cover and mark.
- `manifest.json` records dimensions, generation settings, and SHA-256 hashes.

## Usage

- Keep the complete mark visible with clear space around it.
- Use the off-white background or another high-contrast neutral surface.
- Do not crop, stretch, rotate, add glow, or place the mark over busy imagery.
- Include descriptive alt text such as: "Prompt cards pass through bounded builder gates into retained evidence and a selected browser-world proof."

## Regeneration

Use the Repo Image Studio workflow and generate replacements into a separate review directory. Validate dimensions, alpha corners, mask coverage, hashes, and Human View before replacing any tracked asset.
